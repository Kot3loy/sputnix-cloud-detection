## 2. Обучающий датасет — 38-Cloud

Выбран открытый датасет **38-Cloud** («Cloud Detection in Landsat 8»
производной разметки SPARCS, Sentinel-2-совместимые патчи 384×384;
используется общепринятая версия с RGB+масками). Источник: зеркало на
HuggingFace `jaygala223/38-cloud-train-only-v1` (без регистрации, parquet,
2 шарда по ~377 МБ = **754 МБ**, 8400 строк: колонки `image` RGB 384×384 +
`label` маска 0/255).

Распаковано в `data/processed/`: **train 7580 пар, val 820 пар** PNG.

Допущения, связанные с датасетом:

1. 38-Cloud — космические снимки другого сенсора, чем камеры кубсатов
   Спутникс → возможен domain gap; для кейса этого достаточно, развитие
   описано в презентации (fine-tune на размеченных снимках Спутникс).
2. Используются RGB-каналы (у кубсатов именно RGB-камера).
3. Train/val сплит случайный (seed=42, 10% валидация).

## 5. Эксперименты по домен-гэпу (2026-11-08/09, реальные прогоны)

Модель, обученная только на 38-Cloud, при инференсе «в лоб» на некалиброванных
снимках кубсатов считала синюю атмосферную дымку облаками (ясный кадр над
рекой → 99% облачности). Проверены три подхода:

| Вариант | Ясная река (истина ~3–5%) | Океан+фронт (истина ~70–80%) | Синтетика 97% облаков | Вердикт |
|---|---|---|---|---|
| raw (без предобработки) | 99.9% ✗ | 98.9% ~ | 97.5% ✓ | дымку принимает за облака |
| растяжка контраста 2–98% (predict.py по умолчанию) | 23.5% ✓ | 72.8% ✓ | 62% ✗ | **лучший**, принят основным |
| haze-аугментация при обучении | 99.2% ✗ (raw) / 0.5% (stretch) | 37.6% (raw) / 63.5% (stretch) | 100% (raw) | не решает обе ситуации сразу |

Итоговая конфигурация: **модель без haze-аугментации + адаптивная
предобработка на инференсе** (`predict.py::adaptive_preprocess`, флаг
`--no-stretch` отключает). Правило по яркостной статистике кадра: если
p2 яркости < 130 (видны тёмные пиксели поверхности сквозь дымку) —
перцентильная растяжка 2–98%; иначе кадр однородно-яркий (сплошная
облачность или яркая поверхность) — обработка исходных данных без
искажений. Правило корректно на всех 8 референсных кадрах обоих доменов.

Финальная модель (16 эпох, val IoU 0.9015) с адаптивной предобработкой на
демо-наборе: ясная река → 1.3% (истина ~3–5%), облачный океан → 69.4%
(истина ~70–80%), синтетика 82–89% облаков → 96.4–96.9% и отбракована.

Ограничение: гипотетический реальный кадр с облачностью 95–100% и без
тёмных пикселей попадает в raw-режим; за счёт haze-слепоты raw-режим
такие кадры оценивает высоко (98–99%) — отбраковка срабатывает верно.
Haze-эксперимент сохранён в `outputs/checkpoints/best_model_haze.pth`
и флаге `--haze-aug` у train.py как абляция для защиты.
